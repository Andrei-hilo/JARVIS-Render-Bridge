How the bridge works

Discord user → BDFD custom command → JARVIS AI → reply returned to BDFD → Discord channel.

BDFD cannot reach localhost on your phone. You need a trusted HTTPS relay or host that forwards traffic securely to JARVIS. Never expose Pydroid's plain HTTP development server directly to the public internet.
